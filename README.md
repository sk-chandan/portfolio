# SK Chandan Portfolio

A modern, animated, responsive portfolio built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the GitHub and LinkedIn placeholder URLs in `index.html`.
2. Add your CV as `SK-Chandan-CV.pdf` in this folder.
3. Add certificate images to `assets/` if you want certificate previews.
4. Publish the folder with GitHub Pages or another static hosting service.

## Current skills shown
C, C++, Java, Python, HTML, CSS, JavaScript, PHP, MySQL, DBMS, Data Structures & Algorithms, AI/ML basics, Web Development.
